# DZStore OS

AI sales assistant SaaS for Algerian online stores.

## MVP
- Merchant dashboard
- Product catalog
- Customer conversations
- AI-assisted replies
- Order capture and status tracking
- Arabic/French support
- WhatsApp/Instagram integration layer (next phase)

## Stack
- Next.js + TypeScript
- Tailwind CSS
- Supabase (Auth + Postgres)
- Vercel

## First pilot
Al Miraj Education will be used as the first real-world pilot after the standalone MVP is stable.
